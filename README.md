## 为什么选择 ZhiCms

### 核心优势

| 维度 | 优势 | 说明 |
|------|------|------|
| **全链路闭环** | 采集→发布→推广→成交→佣金 | 不做一半的事：从淘客 API 对接、商品入库、内容创作、用户跳转到佣金追踪，全流程都在一套系统内完成。你只需要关注运营本身 |
| **零门槛搭建** | 图形化安装向导，3 步完成 | 环境检测 → 填数据库信息 → 设管理员密码，3 分钟内出站。内置 Nginx/Apache/IIS 配置，主流主机面板均可一键部署 |
| **多平台商品** | 淘宝/天猫 + 京东 + 拼多多 + 唯品会 | 对接大淘客 + 好单库两大 API 平台，同一关键词跨平台搜商品、比价，找到性价比最高的推荐给用户 |
| **四合一插件** | 原生格式 + WordPress / Z-Blog / Emlog | 独一无二的插件兼容引擎。你可以在 ZhiCms 上安装其他 CMS 生态的插件，上万个存量插件直接复用 |
| **多端覆盖** | PC 网站 + H5 移动站 + 微信小程序 | 一套后台管理全部终端。PC 端优雅的 CMS 风格页面，H5 端流畅的移动适配，小程序端 uni-app 开发，数据完全互通 |
| **AI 驱动** | 人工智能导购 + 内容辅助 + 图像生成 | 内置 AI 开放平台，对接 DeepSeek / 通义千问 / Kimi 等大模型。用户说"我想买一个适合送女朋友的礼物"，AI 自动搜索站内商品推荐 |
| **微社区系统** | 板块/小组/帖子 + 多层嵌套回复 | 自带"种草社区"，用户可发帖分享好物、嵌入商品卡片。社区内容同时反哺 SEO，形成"内容 → 流量 → 转化"飞轮 |
| **SEO 全优化** | 独立 TDK + 伪静态 + 自动 Sitemap + 搜索引擎推送 | 每个页面可独立设置标题/关键词/描述，生成 sitemap.xml，支持百度、Bing 主动推送，上线即收录 |
| **安全可靠** | CSRF + XSS 防护 + SQL 注入防御 | 表单 Token 验证、输入过滤、数据绑定防注入、开放重定向白名单。生产环境关闭调试模式，data 目录禁止外部访问 |

### 与同类方案对比

| 对比点 | WordPress + 淘客插件 | 其他导购 CMS | ZhiCms |
|--------|---------------------|-------------|--------|
| 部署难度 | 需手动装 WP + 插件 + 主题 | 各有门槛 | **图形化安装，3 分钟** |
| 性能开销 | WP 较重，200+ 数据库查询 | 参差不齐 | **轻量框架，按需查询** |
| SEO | 需 Yoast 等插件 | 一般 | **内置完整 SEO 方案** |
| 插件生态 | 极丰富 | 闭源 | **兼容 WP/ZB/Emlog 三种插件** |
| 淘客对接 | 靠插件 | 通常仅一种 | **大淘客 + 好单库双平台** |
| 微社区 | 需 bbPress 等 | 无 | **内置完整社区系统** |
| AI 能力 | 靠插件 | 无 | **内置 AI 开放平台** |
| 多端 | 需额外方案 | 有限 | **PC/H5/小程序一套数据** |

## 快速开始

### 1. 上传文件

将全部文件上传到网站根目录。

### 2. 设置目录权限

以下目录需要可写权限（Linux 执行 `chmod -R 777`）：

```
data/
data/config/
data/cache/
data/log/
upload/
```

### 3. 访问安装向导

浏览器访问网站域名，系统检测到未安装会自动跳转到安装向导。

按提示完成三步：
1. **环境检查** — PHP 版本、扩展、目录权限
2. **数据库配置** — 主机、端口、用户名、密码、库名、表前缀
3. **管理员设置** — 账号、密码、站点名称

### 4. 安装完成

- **前台**：`http://你的域名/`
- **后台**：`http://你的域名/index.php?r=manage`

使用安装时设置的管理员账号登录。

## 后台管理详解

### 仪表盘

登录后台后的首页面板，展示关键运营数据：

| 指标 | 含义 |
|------|------|
| 用户数 | 已注册的前台用户总数 |
| 商品数 | 本地选品库中的商品总量 |
| 文章数 | 已发布的发现/好物推荐文章总数 |
| 今日文章数 | 当天发布的文章数量 |
| 今日有效商品数 | 当天更新后仍有效的商品数（优惠券未过期） |

仪表盘还提供：
- **版本检测**：自动检查官方是否有新版本发布
- **一键清除缓存**：清除模板编译缓存和数据库查询缓存，修改配置或模板后使用

---

### 发现管理

发现管理是内容运营的核心，包含两个功能：

#### 发现列表

展示所有已发布的好物推荐文章，每篇文章关联一个或多个商品。支持：
- 关键词搜索文章标题
- 分类筛选
- 编辑文章（修改标题、内容、SEO 信息）
- 删除文章

#### 发布线索

创建新的推荐文章。编辑器中可以：
- 撰写好物推荐文案
- 插入商品卡片（从选品库选择已采集的商品）
- 设置分类和 SEO 关键词

> **一键采集**：点击"采集"按钮，系统自动从好单库素材库拉取朋友圈风格的营销文案和关联商品信息，一键生成并入库，大幅降低内容创作门槛。

---

### 社区管理

管理微社区的全部内容。结构与前台社区一致：板块 > 小组 > 帖子。

| 页面 | 功能 |
|------|------|
| **帖子列表** | 查看所有帖子，支持显示/隐藏切换、删除（会级联删除所有回复） |
| **评论管理** | 查看所有评论和回复，支持置顶切换、删除 |
| **板块管理** | 创建/编辑/删除板块（如"好物分享""数码评测"等），设置排序 |
| **小组管理** | 在板块下创建小组，关联板块，设置排序 |

---

### 页面管理

创建独立单页，适合"关于我们""商务合作""用户协议"等场景。每页支持：
- 自定义标题和正文内容
- 选择不同的显示模板
- 前台通过 `/page/别名` 访问

---

### 电商宝库

商品管理的核心区域，分为本地选品库和联盟库两个模块：

#### 选品库

展示所有已入库的商品，可按分类筛选和关键词搜索。支持：
- 编辑商品信息（标题、价格、图片等）
- 商品置顶（设置置顶起止时间，置顶期间显示在列表最前面）
- 清理过期商品

#### 联盟库

通过大淘客/好单库 API 实时从电商平台拉取商品：

- **多平台切换**：淘宝、京东、拼多多、唯品会四个商品来源
- **搜索筛选**：关键词搜索 + 分类筛选 + 是否有优惠券
- **比价模式**：同一关键词下聚合展示各平台价格，一目了然
- **单条采集**：找到合适的商品，点击"采集"入库
- **批量更新**：系统自动拉取商品最新数据（价格变化、优惠券状态、销量、佣金等），保持库内商品信息新鲜

---

### 用户管理

管理前台注册用户：列表查看、添加/编辑用户信息（用户名/密码/手机号/VIP 标记/锁定状态）。

### 系统设置（详细说明）

系统设置是所有网站配置的集中管理页面，分为 8 个标签页：

#### 基础设置

| 设置项 | 类型 | 说明 | 生效位置 |
|--------|------|------|---------|
| **网站名称** | 文本 | 显示在浏览器标题栏、页面 `<title>` 标签中 | 全站标题 |
| **网站地址** | URL | 完整的网站域名，如 `https://www.example.com`，用于生成 sitemap、推送 URL、RSS 等 | SEO 相关功能 |
| **备案号** | 文本 | ICP 备案号，显示在页面底部 | 全站页脚 |
| **网站关键词** | 文本 | 多个关键词用英文逗号分隔，作为默认 `meta keywords` | 全站 `<head>` |
| **网站描述** | 多行文本 | 网站简介，作为默认 `meta description` | 全站 `<head>` |
| **关于我们** | 多行文本 | 在"关于我们"页面展示的内容 | 关于我们页面 |
| **底部版权** | 文本 | 页脚显示的版权信息，支持 HTML | 全站页脚 |
| **网站 LOGO** | 图片 URL | 网站标志图片，显示在顶部导航栏 | 全站头部 |
| **二维码** | 图片 URL | 用于微信扫码等场景的二维码图片 | 侧边栏/联系方式 |
| **默认图片** | 图片 URL | 当文章或商品没有配图时使用的占位图 | 无图内容 |
| **移动端首页风格** | 下拉选择 | H5 移动端首页的展示模板（超级搜索/小样种草机/好单线报） | H5 首页 |
| **关闭站点** | 开关 | 开启后前台无法访问，显示关闭提示 | 全站前台 |
| **关闭提示** | 多行文本 | 站点关闭时访客看到的信息 | 全站前台 |
| **CDN 设置** | URL | 静态资源的独立域名，留空使用站点域名 | 全局静态资源 |
| **下载链接** | URL | APP/客户端下载地址 | 下载入口 |
| **缓存时间** | 数字（秒） | 页面静态缓存有效期，如 3600（1小时） | 前台各页面 |
| **分页条数** | 数字 | 每页显示的文章/商品/帖子数量 | 全站列表页 |
| **水印开关** | 开关 | 上传图片时是否自动添加文字水印 | 上传功能 |
| **水印文字** | 文本 | 水印文字内容 | 上传图片 |

#### URL 设置

| 设置项 | 说明 |
|--------|------|
| **网站模式** | 安全模式（生产环境，隐藏错误）或调试模式（显示错误信息，用于开发） |
| **首页默认访问** | 选择用户打开首页时默认展示哪个频道：国内折扣/海淘折扣/优惠券/排行榜 |
| **伪静态开关** | 启用后 URL 变为 `/view-123.html` 格式，需服务器支持 URL Rewrite |

#### SEO 设置

可以为网站每个重要页面**单独配置**标题、关键词和描述：

| 页面 | 可配置项 |
|------|---------|
| 网站首页 | 首页标题、关键词、描述 |
| 大牌风尚（品牌页） | 品牌列表页标题、关键词、描述 |
| 风云榜（排行榜） | 排行榜页面标题、关键词、描述 |
| 优惠券中心 | 优惠券列表页标题、关键词、描述 |

> 文章详情页的 SEO 信息取自文章本身，不需要在此配置。

#### API 设置

| 设置项 | 说明 | 获取方式 |
|--------|------|---------|
| 官网 API 地址 | ZhiCms 官网接口地址 | 使用默认值 |
| 官网 appid / secretkey | 官网授权凭证 | 联系官方获取 |
| 淘宝联盟 appkey / secretKey | 淘宝联盟开发者凭证 | [淘宝联盟开放平台](https://pub.alimama.com/) |
| 阿里妈妈 PID | 推广位 ID（三段式） | 阿里妈妈 → 推广管理 → 推广位 |
| 大淘客 appKey / appSecret | 大淘客开放平台凭证 | [大淘客官网](https://www.dataoke.com/) |
| 好单库 appKey | 好单库开放平台凭证 | [好单库官网](https://www.haodanku.com/) |
| 转链模式 | 选择使用大淘客(DTK)还是好单库(HDK)进行商品链接转换 | 与使用的 API 平台对应 |

#### 短信设置

| 设置项 | 说明 |
|--------|------|
| 短信接口地址 | 第三方短信平台的 API 地址 |
| 短信模板 | 注册验证码、密码重置等场景的短信文案 |

#### SEO 推送

自动将网站 URL 推送给搜索引擎，加速收录：

| 平台 | 说明 |
|------|------|
| **百度站长平台** | 填写百度推送 Token，启用后自动推新文章到百度 |
| **Bing Webmaster** | 填写 Bing API Key，覆盖必应、Yahoo、DuckDuckGo |
| **Sitemap & Ping** | 自动生成 `sitemap.xml` 和 `sitemap.txt`，并向搜索引擎发送 Ping |
| **自动推送策略** | 定时自动推送（每小时）+ 发布时即时推送，二选一或同时启用 |
| **手动推送** | 输入 URL 列表手动推送，或一键推送最新 50 篇 / 全站 |
| **推送日志** | 查看最近 20 条推送记录（时间、URL、数量、各平台结果） |

#### 互动设置

| 设置项 | 说明 |
|--------|------|
| 开启评论功能 | 关闭后所有文章详情页评论区不显示 |
| 开启社区功能 | 关闭后前台社区入口和页面无法访问 |
| 允许未登录评论 | 开启后访客可通过"昵称+邮箱"提交评论 |
| 评论需要审核 | 开启后新评论默认隐藏，管理员审核后才显示 |
| 评论间隔 | 同一 IP 在 N 秒内无法再次评论（防刷，建议 60 秒） |

#### AI 对话

配置小程序 AI 导购功能：

| 设置项 | 说明 |
|--------|------|
| 开启 AI 对话 | 总开关，关闭后小程序使用模拟回复 |
| 主题色 | 小程序 AI 对话界面的主题色 |
| 默认 AI 角色 | 购物顾问/时尚达人/数码专家/美食家/智能助手 |
| 服务商标识 | API 提供商，如 deepseek |
| 接口地址 | OpenAI 兼容的 API 地址 |
| API Key | 仅在服务器端保管，不下发到小程序 |
| 模型名称 | 如 deepseek-chat |
| 温度 | 控制回答的创造性（0-1） |
| 最大 Token | 回答的最大长度限制 |
| 访问令牌 | 小程序请求 AI 时需携带的 Bearer 令牌 |

## 使用指南

以下是从零开始运营一个导购网站的完整流程：

### 第一步：完成初始化配置

1. 登录后台，进入 **系统设置 → 基础设置**
2. 设置网站名称、网址、Logo、关键词和描述
3. 填写备案号（如果有）和底部版权信息
4. 进入 **SEO 设置**，为首页、品牌页、排行榜、优惠券页分别配置 TDK（标题/关键词/描述）
5. 如果已申请淘客 API，进入 **API 设置**，填入大淘客或好单库的 AppKey 和 AppSecret，以及淘宝联盟 PID
6. 进入 **URL 设置**，开启伪静态（需服务器支持），选择首页默认展示

### 第二步：搭建商品库

1. 进入 **电商宝库 → 联盟库**
2. 在搜索框输入目标品类关键词（如"连衣裙""无线耳机"）
3. 切换平台标签查看淘宝、京东、拼多多、唯品会的商品
4. 勾选"有优惠券"筛选高性价比商品
5. 点击商品卡片上的"采集"按钮，商品即入库到本地选品库
6. 定期点击"批量更新"，让系统自动更新商品的价格、优惠券状态和销量

> **技巧**：建议每个品类采集 50-100 个商品，保持商品信息新鲜有利于 SEO 收录。

### 第三步：发布内容

#### 方式一：手动创作（适合精品内容）

1. 进入 **发现管理 → 发布线索**
2. 撰写推荐文案，例如"实测 5 款百元以内无线降噪耳机，第 3 款性价比炸裂"
3. 在编辑器中插入从选品库选择的商品卡片
4. 设置文章分类和 SEO 关键词
5. 发布

#### 方式二：一键采集（适合快速起量）

1. 进入 **发现管理 → 发现列表**
2. 点击顶部的"采集"按钮
3. 系统自动从好单库素材库拉取朋友圈营销文案和关联商品
4. 自动生成带商品卡片的文章，一键入库

> **技巧**：新品上架时用一键采集快速填充内容，精品内容用手动创作打磨质量。

### 第四步：上线运营

1. **开通社区**：进入 **互动设置**，打开社区开关，设置板块和小组
2. **添加广告**：进入 **广告管理**，上传首页轮播广告图
3. **SEO 推送**：进入 **SEO 推送**，配置百度/Bing Token，开启自动推送
4. **提交搜索引擎**：将网站提交到百度站长平台、Bing Webmaster、Google Search Console
5. **生成 Sitemap**：开启 Sitemap 功能，系统自动生成并 ping 搜索引擎

### 第五步：社区冷启动

1. 进入 **社区管理 → 板块管理**，创建 3-5 个板块（如"数码控""穿搭日记""居家好物"）
2. 在板块下创建 1-2 个小组
3. 发布 10-20 篇种子帖子（管理员账号，带商品卡片）
4. 当有自然用户互动后，社区会自己运转起来

### 第六步：数据分析与 SEO 优化

1. 定期查看后台仪表盘的文章数和商品数增长趋势
2. 查看 **SEO 推送 → 推送日志**，确认推送是否成功
3. 在百度站长平台查看收录情况和搜索关键词
4. 根据搜索关键词调整 SEO 设置中的 TDK
5. 定期进入联盟库做"批量更新"，淘汰失效商品

## 配置说明

### 数据库配置

`data/config/db.php` — 安装时自动写入，支持读写分离：

```php
'DB' => array(
    'default' => array(
        'DB_TYPE'    => 'MysqlPdo',   // MysqlPdo | Mysqli
        'DB_HOST'    => 'localhost',
        'DB_USER'    => 'root',
        'DB_PWD'     => '',
        'DB_PORT'    => '3306',
        'DB_NAME'    => 'zhicms',
        'DB_CHARSET' => 'utf8mb4',
        'DB_PREFIX'  => 'yun_',
        'DB_CACHE'   => 'DB_CACHE',
    ),
),
```

### 路由配置

`data/config/rule.php` — 自定义伪静态规则：

```php
'REWRITE_ON' => 1,
'REWRITE_RULE' => array(
    'index.html'           => 'index/index/index',
    'view-<id>.html'       => 'index/index/view/id=<id>',
    'shequ.html'           => 'index/forum/index',
    'shequ-<gid>.html'     => 'index/forum/group/gid=<gid>',
    'tiezi-<id>.html'      => 'index/forum/view/id=<id>',
    // ... 更多规则
),
```

### 模板引擎配置

`data/config/global.php`：

```php
'TPL' => array(
    'TPL_PATH'   => '',
    'TPL_SUFFIX' => '.html',
    'ENGINE'     => 'legacy',  // 'legacy' 或 'think'（ThinkTemplate）
),
```

### 模板开发
- 路径：`app/{模块}/view/{控制器}/{方法}.html`
- Legacy 语法：`{$var}` / `{foreach $list as $v}` / `{if $cond}`
- Think 语法：`{$var}` / `{volist name="list" id="v"}` / `{include file="..."}`
- 编译缓存：`data/cache/tpl/`，缓存 365 天，修改模板后需在后台清除缓存

## Web 服务器配置

### Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/zhicms;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 禁止访问 data 目录
    location ~ /data/ {
        deny all;
    }
}
```

### Apache

项目内置 `.htaccess`，确保 Apache 开启 `mod_rewrite`。

### IIS

导入 `web.config` 或手动配置 URL Rewrite 模块。

## 常见问题

### 安装相关

**Q: 安装时提示"数据库连接失败"？**
检查主机地址、端口、用户名、密码是否正确，确认 MySQL 服务已启动。如果数据库不存在，安装向导会自动创建。

**Q: 安装后访问页面空白？**
检查 `data/config/db.php` 数据库配置是否正确，查看 `data/log/` 错误日志，确认 PHP 版本 >= 7.0。

**Q: 如何重新安装？**
删除 `data/config/install.lock` 文件，访问网站会自动跳转到安装向导。

### 运营相关

**Q: 如何对接淘宝客？**
后台 → 系统设置 → API 设置，填入大淘客或好单库的 AppKey 和 AppSecret，以及淘宝联盟 PID。

**Q: 商品没有佣金？**
确保已配置正确的 PID，转链方式与 API 密钥匹配（大淘客密钥 → DTK 转链，好单库密钥 → HDK 转链）。

**Q: 如何添加新商品？**
方式一：后台 → 电商宝库 → 联盟库 → 搜索商品 → 点击"采集"按钮入库
方式二：后台 → 电商宝库 → 联盟库 → "批量更新"拉取最新商品

**Q: 如何发布文章？**
方式一：手动发布 — 后台 → 发现管理 → 发布线索
方式二：一键采集 — 后台 → 发现管理 → 顶部"采集"按钮

**Q: 首页如何显示内容？**
确保已发布文章，且文章状态为正常。可在 URL 设置中选择首页默认展示哪个频道。

**Q: 如何让搜索引擎快速收录？**
后台 → 系统设置 → SEO 推送 → 配置百度/Bing Token → 开启自动推送 → 手动推送全站一次 → 等待 24-48 小时。

### 技术相关

**Q: 如何切换模板引擎？**
修改 `data/config/global.php`，`TPL.ENGINE` 设为 `legacy` 或 `think`。修改后需清除缓存。

**Q: 修改了模板但没生效？**
进入后台首页，点击"清除缓存"按钮。模板编译缓存默认有效 365 天，修改模板后必须手动清除。

**Q: 如何添加自定义伪静态规则？**
在 `data/config/rule.php` 的 `REWRITE_RULE` 数组中添加正则匹配和路由映射。

**Q: 如何开发插件？**
在 `plugins/` 下创建目录，添加 `plugin.json` 和 `Plugin.php`，继承 `BasePlugin` 并实现 `register()` 方法。也可直接放入 WordPress/Z-Blog/Emlog 格式的插件，系统自动识别。

**Q: 如何开启调试模式？**
`data/config/rule.php` 中设 `DEBUG` 为 1，错误信息直接在页面显示。生产环境务必关闭。

**Q: 如何备份网站？**
方式一：后台 → 数据库备份
方式二：导出 MySQL 数据库 + 压缩打包整个网站目录
