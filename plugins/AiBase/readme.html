优杰AI大模型连接器 (AiBase)

这是一个为优杰系列子插件提供底层大模型接口调用的核心公共插件，本身完全免费。

为什么需要这个底座插件？

如果您在站点中安装了多个AI功能插件，例如提示词助手、智能招聘生成器等，以往每个插件都需要单独配置一次 API Key 和 API 接口地址。这不仅繁杂，而且一旦遇到密钥过期或中转节点变动，需要逐个插件进入修改，非常难以维护。

通过安装本连接器，您只需要在底座中一次性配置好您的 API 密钥，所有依赖本底座的优杰AI子插件即可自动共享该接口配置，实现开箱即用。日后如需更换密钥或微调接口参数，也只需在底座中修改一处即可。

主要功能特点

  • 平台兼容性：支持标准的 OpenAI API 格式接口。内置了 DeepSeek、OpenAI、Claude、阿里云百炼、百度千帆、腾讯混元、智谱 AI、Moonshot 等大语言模型服务配置。
  • 流式数据传输：底层支持 Server-Sent Events 流式通信协议，使子插件调用大模型时，文本生成可以像打字机一样逐字显现，避免后台因长时间等待而产生假死卡顿。
  • 本地数据加密：所有配置的 API Key 在写入本地数据库时均进行加密处理，同时后台提供明文/密文切换防窥视显示。
  • 连通性测试：提供快捷的“测试连接”功能，若接口无法连通，会直观展示报错原因，方便您排查是否为密钥填写错误或接口地址书写不规范等问题。

注意事项

如果您的服务器位于中国大陆境内，直连境外 API 接口（如 OpenAI 或 Claude 官方接口）可能会发生网络连接超时。推荐配合国内的中转代理，或者直接选择 DeepSeek 等国内平台服务，配置相对更加省心。
